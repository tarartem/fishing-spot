# Database Directory (`db/`)

Contains SQL migrations and seed data matching [`specs/03-data-and-api/database-schema.md`](../specs/03-data-and-api/database-schema.md).

- `db/migrations/` — Sequential SQL schema migration files (PostgreSQL + PostGIS).
- `db/seed/` — Seed data for common fish species, fishing techniques, and sample water bodies for local testing.
